Forward model: from the true sample to the observed peak

Peak positions from Bragg's law for fcc Cu, a = 3.6150 Å, Cu Kα1 = 1.540562 Å and Kα2 = 1.544390 Å (Bearden 1967), Kα2/Kα1 = 0.5; relative intensities of JCPDS 04-0836 as in the package.

size (Lorentzian): fL = Ktrue λ / (D cos θ)  ·  strain (Gaussian): fG,ε = 4 ε tan θ  ·  instrument (Gaussian): finst from Caglioti
fG = √(fG,ε² + finst²)  →  observed FWHM and η from the Thompson–Cox–Hastings formulas

The observed width and η are what a perfect, noise-free fit of the Kα1 component would return; real fits add their own error.

Analysis: what xrd_analysis does with the observed width

quadratic: β = √(fobs² − finst²)  ·  Voigt: split fobs into G and L parts with the inverse TCH mapping, subtract the instrument (G quadratically, L linearly), recombine with f = 0.5346 fL + √(0.2166 fL² + fG²)
D = K λ / (β cos θ),   λ = Kα1; flags: fobs/finst < 1.2 unreliable, D outside 2–200 nm warning

The Scherrer equation attributes all sample broadening to size, so microstrain makes it underestimate the size, more at high angle. The quadratic correction treats both widths as Gaussian; the size broadening is Lorentzian, so it under-corrects. With the Voigt correction and pure size broadening the size is recovered exactly; when microstrain adds a Gaussian part, splitting (TCH) and recombining (Olivero–Longbothum) use slightly different width formulas.

Checks

The instrument parameters are illustrative values for a laboratory diffractometer, not a calibration: the repository's config.yaml leaves U, V and W to be calibrated with a LaB6 standard (NIST SRM 660c).
